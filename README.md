# Neural Style Transfer

## Overview
This project demonstrates **Neural Style Transfer**, a technique that generates a new image by combining:
- **Content image** → the original subject of the image
- **Style image** → the artistic style to apply

The final output keeps the content intact while transferring the visual style of the reference image.

---

## Objective
- Learn how CNNs extract content and style features
- Understand content loss and style loss
- Generate stylized images without training a neural network from scratch

---

## Tools & Technologies
- Python
- Google Colab
- PyTorch
- Pre-trained VGG19 model

---

## Methodology
1. Load content and style images
2. Preprocess images for VGG19
3. Extract features and compute **content loss** and **style loss**
4. Optimize the input image iteratively to minimize losses
5. Save and visualize the final stylized output

---

## Output
The project generates a stylized image that combines the content of the original image with the style of the reference image.

**Example:**
- Content: photo of a dancer  
- Style: Picasso painting  
- Output: dancer image in Picasso style

---

## Learning Outcomes
- Neural Style Transfer concept
- Feature extraction using CNNs
- Understanding of content loss and style loss
- Difference between classical and modern generative AI approaches
